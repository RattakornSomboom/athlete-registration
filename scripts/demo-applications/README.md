# ข้อมูลใบสมัครตัวอย่างสำหรับสาธิตต่อคณะกรรมการ

สร้างข้อมูลจริงในฐานข้อมูล (ไม่ใช่โหมดสาธิตแบบอ่านอย่างเดียวของ Excellence) เพื่อให้ช่วงใบสมัคร → ตรวจหลักฐาน → ประกาศผล ใน `docs/COMMITTEE_DEMO.md` สาธิตได้

## ใช้งาน

```bash
node scripts/demo-applications/seed-applications.mjs seed scripts/demo-applications/accounts.local.txt
```

```bash
node scripts/demo-applications/seed-roster.mjs seed
```

ต้องรัน `seed-applications` ก่อน แล้วค่อย `seed-roster` เพราะ roster อ้างใบสมัคร · รหัสผ่านที่สุ่มให้ถูกเขียนลง `accounts.local.txt` ซึ่ง gitignore ไว้แล้ว ทุกบัญชีตั้ง `mustChangePassword` เป็นจริง

## ลบทิ้งหลังนำเสนอ

```bash
node scripts/demo-applications/seed-roster.mjs cleanup
```

```bash
node scripts/demo-applications/seed-applications.mjs cleanup
```

`cleanup` ของ `seed-applications` ลบไฟล์ในที่เก็บเอกสารส่วนตัวด้วย และพิมพ์จำนวนแถวที่เหลือ (ต้องเป็น 0 ทุกช่อง) · `seed` เรียก `cleanup` ให้เองก่อนสร้างใหม่ จึงรันซ้ำได้

## สิ่งที่ถูกสร้าง

ทุกแถวมี `id` ขึ้นต้นด้วย `zzdemo-` และรหัสนิสิต `699000xx` จึงแยกออกจากข้อมูลจริงได้ชัดเจน

| สิ่งที่สร้าง | รายละเอียด |
|---|---|
| `SportQuota` กรีฑา | เพิ่มเข้ากับรายการแข่งขันครั้งที่ 52 (เดิมไม่มีกรีฑา จึงสมัครกรีฑาไม่ได้เลย) โควตา 1/0 เพราะกรีฑาเป็นกีฬาประเภทบุคคล |
| `Club` ชมรมกรีฑา | ประธาน นายสมชาย ใจดี · ใช้เป็นชมรมต้นสังกัดของทั้ง 3 ใบสมัคร |
| `ClubRoster` สถานะ SUBMITTED | จำเป็น เพราะเจ้าหน้าที่จะเห็นใบสมัครเฉพาะที่อยู่ใน roster ที่ส่งแล้ว หรือที่แนบหนังสือไม่มีชมรม (`lib/application-query.ts`) |
| ผู้ใช้ + โปรไฟล์ + ใบสมัคร 3 ราย | ดูตารางถัดไป |
| เอกสารแนบ 4 ไฟล์ต่อคน | รูปถ่าย (PNG) สำเนาบัตรประชาชน สำเนาบัตรนิสิต ใบรับรองการเป็นนิสิต (PDF) อัปโหลดเข้าที่เก็บส่วนตัวจริงและเปิดผ่าน `/api/documents/{id}/download` ได้ · ใบ UP Academy และผลสมรรถภาพตั้งเป็น `-` (เป็นเอกสารที่ซ่อนใน UI อยู่แล้ว) |

| รหัสนิสิต | ชื่อ | ประเภท | GPAX | สถานะ | ใช้สาธิตเรื่อง |
|---|---|---|---|---|---|
| 69900001 | นายเกียรติศักดิ์ แสนสุข | ลู่ (ชาย) | 3.20 | กองกิจฯ อนุมัติ | ผ่านครบ 3 เกณฑ์ และพร้อมประกาศผลในหน้า `/staff/selection` |
| 69900002 | นางสาวจิรารัตน์ ดวงแก้ว | ลู่ (หญิง) | 1.85 | รอการพิจารณา | ระบบขึ้น "เสี่ยงผิดระเบียบ กกมท." และชี้ว่า GPAX ตกเกณฑ์ |
| 69900003 | นายธีรภัทร อินทจักร | ลาน (ชาย) | 2.75 | ชมรมอนุมัติ / รอกองกิจฯ | ใบที่เจ้าหน้าที่ยังต้องกดอนุมัติหรือไม่อนุมัติ |

อายุคำนวณจากวันเกิดเทียบปีมหกรรม ทั้งสามคนอยู่ในเกณฑ์ ≤ 28 ปี และไม่มีประวัติเข้าร่วมเดิม จึงผ่านเกณฑ์ข้อ 2 และ 3 ทุกคน

## ข้อควรรู้

- ไม่แก้ schema และไม่รัน migration ใด ๆ เขียนเฉพาะข้อมูลด้วย SQL ผ่าน `pg` และอัปโหลดไฟล์ด้วย service role key จาก `.env`
- ถ้ากดอนุมัติ/ไม่อนุมัติ/ประกาศผลตอนซ้อม สถานะจะเปลี่ยนจริง ให้รัน `seed` ใหม่เพื่อคืนสถานะตั้งต้น
- เอกสารเป็น PDF/PNG เปล่าที่มีข้อความ "DEMO DOCUMENT - NOT A REAL RECORD" ไม่ใช่เอกสารของบุคคลจริง
- หัวข้อ "ตัวจริง 0 คน · ตัวสำรอง 0 คน" และป้าย "ยังไม่ได้ระบุ" ในหน้าชมรมเป็นเรื่องปกติของกีฬาประเภทบุคคล เพราะ roster ใช้สถานะ `selected` ไม่ใช่ตัวจริง/สำรอง
