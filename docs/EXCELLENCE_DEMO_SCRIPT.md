# สคริปต์สาธิต: สู่ความเป็นเลิศ (กรีฑาประเภทลู่)

ข้อมูลสาธิตทั้งหมดเป็นข้อมูลจำลอง (`lib/excellence-demo.ts`) นักกีฬา 10 คน รายการ 100 / 200 / 400 เมตร ชายและหญิง และอ่านได้อย่างเดียว

## เตรียม
1. เข้าสู่ระบบด้วยบัญชี STAFF หรือ ADMIN
2. เปิดเมนู "สู่ความเป็นเลิศ" แล้วติ๊ก "แสดงข้อมูลสาธิต" (หรือเปิด `/staff/excellence?demo=true`)

## ลำดับการเล่า (ประมาณ 5 นาที)
1. **ภาพรวม:** ตัวเลขสรุป 4 ค่า (นักกีฬา / ถึงเป้า / มีแผน / ทดสอบซ้ำ) นับเป็นจำนวนคน ตารางมี 1 แถวต่อคนต่อรายการ
   - กรองเป็น 100 เมตร + หญิง ให้เห็นว่าเป้าแยกตามรายการและเพศ
   - ชี้สถานะ 4 แบบ: ถึงเป้า, ยังไม่ถึงเป้า, ยังไม่ตั้งเป้า (นายวรเมธ 200 ม.), ยังไม่มีผลแข่ง (นางสาวอรอุมา)
2. **เป้าเวลา:** เปิดแท็บ "เป้าเวลา (Benchmark)" ให้เห็นว่าเจ้าหน้าที่ตั้งเป้าเองทีละรายการ และ 110 ม.ข้ามรั้วมีเฉพาะชาย
3. **รายคน: นายภานุวัฒน์ ศรีสุข (100 ม.)**
   - ผลแข่งมีป้าย PB / SB และ Gap +0.48s
   - จุดอ่อน: แรงระเบิดขา (ต่ำ), ความเร็ว 40 ม. (พอใช้)
   - แผนพัฒนามี 2 ข้อ ผูกกับ 2 สถานีนั้น
   - ทดสอบซ้ำ: แรงระเบิดขาดีขึ้น, เวลา 11.48 → 11.30 (−0.18s เกินช่วงคลาดเคลื่อน ±0.1s) จึง "ดีขึ้น"
4. **รายคน: นางสาวพิมพ์ชนก แก้วมณี (100 ม.):** ความอ่อนตัวดีขึ้น แต่เวลา 12.88 → 12.84 (−0.04s) อยู่ในช่วงคลาดเคลื่อน ระบบจึงบอกว่า "ไม่เปลี่ยนชัดเจน" ไม่ได้อ้างว่าดีขึ้น
5. **รายคน: นางสาวสุภาวดี จันทร์หอม (400 ม.):** แรงระเบิดขายังเท่าเดิม และเวลา +0.30s ยังอยู่ในช่วง ±0.31s แสดงว่าระบบไม่ตีความการเปลี่ยนแปลงเล็กน้อยเกินจริง

## ข้อควรพูด
- การเปลี่ยนแปลงหลังแผนเป็นการติดตามผล ไม่ได้พิสูจน์ว่าเกิดจากแผนฝึกเพียงอย่างเดียว
- SWC = ค่าที่มากกว่าระหว่าง 0.1 วินาที (ความคลาดเคลื่อนของการจับเวลาด้วยมือ) กับ 0.5% ของเวลาเดิม
